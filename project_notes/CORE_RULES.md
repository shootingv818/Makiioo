# قواعد هسته

## فایل‌های ممنوع برای بازنویسی

- `account_conn.py`
- `rubika_client.py`
- `worker.py`
- `db.py`
- `main.py`

این فایل‌ها تا حد ممکن باید byte-identical بمانند. منطق پایه اتصال و session نباید دست‌کاری یا بازنویسی شود.

## شیوه تغییر

- تغییرات فقط افزایشی و ایزوله باشند.
- مسئولیت‌های جدید در ماژول‌های جدا نگه داشته شوند.
- جدول‌های اختصاصی ماژول‌های جدید می‌توانند در همان DB ساخته شوند؛ بازنویسی `db.py` لازم نیست.
- تغییر احتمالی `bot.py` فقط hook، دکمه یا route کوچک و مشخص باشد.
- بازطراحی کلی ربات، شکستن `bot.py` و تغییر معماری پایه خارج از محدوده است.
- push مستقیم یا force-push به `production` ممنوع است؛ تغییر باید روی شاخه جدید و از طریق PR انجام شود.
